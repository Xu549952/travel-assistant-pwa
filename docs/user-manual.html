一、应用简介

旅行助手是一款个人旅行规划工具，帮助您高效管理行程安排、追踪旅行预算、记录旅行日记。支持离线使用，特别适合旅行中网络不稳定的场景。

核心功能

行程管理
时间轴展示，冲突检测
💰

📖

二、安装与启动

Android 安装

  1. 将 app-release.apk 传输到手机（USB/微信/云盘）
  2. 手机上点击 APK 文件，允许"安装未知应用"
  3. 点击"安装"，等待安装完成
  4. 在桌面找到"旅行助手"图标，点击启动
首次启动：系统会请求通知权限和位置权限，建议全部允许以获得完整功能体验。

Web 版本（浏览器使用）

  1. 访问 https://xu549952.github.io/travel-assistant-pwa/travel-assistant.html
  2. 浏览器菜单选择"添加到主屏幕"即可像原生应用一样使用
  3. 支持 Chrome、Edge、Safari 等主流浏览器

三、界面导航

应用底部有 6 个导航标签，点击切换不同功能模块：

标签 功能 说明
首页 行程概览 出发倒计时、预订截止提醒、预算摘要
行程 每日安排 时间轴展示，活动详情，冲突警告
预算 费用管理 分类预算，逐日分配，收支统计
清单 待办事项 预订清单，出发清单，打包清单
日记 旅行记录 图文日记，照片附件
更多 设置与工具 导入导出、日历导出、备份、语音备忘
顶部栏：显示当前行程名称、日期范围，点击搜索图标可搜索行程内容，月亮图标切换夜间模式。

四、行程管理

查看行程

点击底部"行程"标签，进入时间轴视图。每一天的活动按时间顺序排列，包含：

  • 时间段：活动的开始和结束时间
  • 活动名称：如"漓江三星游船"、"入住酒店"
  • 分类标签：交通/住宿/餐饮/景点等
  • 详情描述：费用、备注、预订方式等
冲突警告：当两个活动时间重叠，或不同地点间转换时间不足 30 分钟时，会显示黄色冲突标记，请及时调整行程。

多行程切换

在首页点击顶部栏的行程名称，可打开行程列表，切换或创建新行程。

五、预算追踪

预算分类

点击"预算"标签，查看四类预算的分配情况：

  • 门票活动：景点门票、体验项目
  • 餐饮：三餐、零食、饮品
  • 当地交通：出租车、公交、大巴
  • 其他：购物、纪念品等

逐日预算

向下滑动查看逐日预算分配卡片，每张卡片显示当天的预算总额、已花费和剩余金额，以及充足度百分比。

小贴士：点击预算分类可展开明细，记录每笔支出的金额和备注。

六、清单功能

预订清单

点击"清单"标签，查看需要提前预订的项目。每个预订项包含：

  • 项目名称和日期
  • 预订渠道（小程序/携程/美团等）
  • 价格参考
  • 截止提醒天数
  • 勾选框（完成后打勾）

出发清单

点击"智能生成打包清单"按钮，根据行程目的地和天数自动生成建议的打包清单，也可手动添加自定义项目。

进度跟踪：清单标题旁显示完成进度（如 0/6），方便了解整体准备情况。

七、旅行日记

新建日记

  1. 点击"日记"标签进入日记列表
  2. 点击右下角"+"按钮新建日记
  3. 选择关联的行程日期
  4. 输入文字内容，可插入照片
  5. 点击保存完成日记记录

查看日记

日记列表按日期倒序排列，点击任意条目查看完整内容。日记中的照片可点击放大查看。

八、离线地图

地图标记

在行程页面查看地图，各类 POI 使用不同颜色标记：

住宿
景点
交通
餐饮

离线缓存

在有网络时浏览过的地图区域会自动缓存。旅行中即使无网络，已缓存的地图仍可查看和定位。

建议：出发前在有 WiFi 的环境下打开地图，浏览目的地周边区域，确保瓦片已缓存。

九、攻略导入

支持的格式

  • Markdown (.md)：识别标题、时间、费用、清单
  • Word (.docx)：自动转换为 HTML 后解析
  • 纯文本 (.txt)：按 Markdown 规则解析
  • JSON (.json)：支持通用 Schema 和 V6.0 导出格式

导入步骤

  1. 点击"更多"标签，选择"导入攻略"
  2. 选择要导入的文件
  3. 系统自动解析并显示预览
  4. 检查预览结果（绿色=通过，橙色=警告，红色=错误）
  5. 如有需要可调整内容
  6. 确认无误后点击"导入"完成
文件限制：单文件最大 10MB（JSON 5MB），超出限制的文件无法导入。

十、数据导出与备份

本地导出

在"更多"中选择"导出数据"，可将行程数据导出为 JSON 文件，保存到本地或分享给他人。

日历导出

选择"导出日历"，支持两种方式：

  • .ics 文件：下载日历文件，导入手机日历应用（含 1 小时提醒）
  • Google Calendar：直接跳转 Google 日历创建事件

云备份（GitHub Gist）

在"更多"中选择"云备份"，可将数据备份到 GitHub Gist。需要配置 GitHub Token（在设置中输入）。

数据安全：所有数据存储在本地（localStorage），不会上传到任何服务器。云备份为可选功能，仅您主动操作时才会执行。

十一、提醒通知

预订截止提醒

对于有截止日期的预订项目，系统会在以下时间发送通知提醒：

  • 截止前 3 天：首次提醒
  • 截止前 1 天：紧急提醒
  • 截止当天：最后提醒
通知去重：同一提醒不会重复发送，使用标签机制确保每条提醒只通知一次。

通知权限

如未收到通知，请检查：设置 → 应用管理 → 旅行助手 → 通知权限 → 确保已开启。

十二、离线使用

旅行助手专为离线场景设计，以下功能在无网络时均可正常使用：

  • 查看和管理行程
  • 预算记录和统计
  • 清单勾选和添加
  • 日记编写和查看
  • 已缓存的地图区域
  • 行程提醒通知
需要网络的功能：天气查询、地图新区域加载、云备份、攻略文件在线下载。建议出发前在有 WiFi 时完成这些操作。
飞行模式测试：可在手机设置中开启飞行模式，验证离线功能是否正常。

十三、常见问题

数据会丢失吗？ 不会。所有数据存储在本地 localStorage 中，关闭应用或重启手机后数据仍在。但卸载应用会清除数据，建议定期使用"导出数据"功能备份。
换手机后数据怎么迁移？ 在旧手机上"导出数据"生成 JSON 文件，将文件传到新手机，在新手机上"导入攻略"选择该文件即可。
为什么地图加载不出来？ 地图需要网络连接加载瓦片。请检查网络连接，或确认该区域是否已缓存。建议出发前预览目的地地图。
通知没有收到？ 请检查：1) 系统通知权限是否开启；2) 电池优化是否限制了后台运行；3) 系统的勿扰模式是否开启。
语音备忘功能怎么用？ 在"更多"中选择"语音备忘"，首次使用需下载中文语音模型（约 50MB），下载完成后即可离线使用语音识别。
支持 iOS 吗？ 目前仅提供 Android 版本。Web 版本可通过 Safari 浏览器使用，并"添加到主屏幕"获得类似原生应用的体验。
如何更新到新版本？ Android 版本：下载新 APK 覆盖安装即可，数据会保留。Web 版本：刷新浏览器即可自动更新。
