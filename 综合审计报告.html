安全审计

14项 · 全部修复
CRITICAL DOM XSS 漏洞 - innerHTML 注入未转义用户输入 SEC-001

问题：多处 innerHTML 赋值使用了未经转义的用户数据（行程标题、描述、费用名称等），可导致存储型 XSS。

影响：攻击者可通过导入恶意构造的 JSON/Markdown 文件，在用户浏览器中执行任意脚本，窃取 localStorage 数据。

修复方案：

对所有用户输入字段使用 escapeHtml() 进行 HTML 实体转义；对富文本内容（item.desc, item.detail）使用 DOMPurify 3.1.6 进行白名单净化。已验证全部 52 处 innerHTML 调用均使用安全的数据处理。

CRITICAL 缺失 Content Security Policy (CSP) SEC-002

问题：无 CSP 头部或 meta 标签，浏览器无法限制外部资源加载。

修复方案：

添加 <meta http-equiv="Content-Security-Policy"> 标签，限制 script-src、style-src、img-src、connect-src 等指令来源。CSP nonce 模式经评估不适用于单文件静态 HTML 架构，已记录决策理由。

HIGH CDN 资源缺少 SRI 完整性校验 SEC-003

问题：6 个 CDN 引用的 JS/CSS 文件未配置 Subresource Integrity，CDN 被篡改时无法检测。

修复方案：

为所有 CDN 资源添加 integrity="sha384-..." 和 crossorigin="anonymous" 属性，覆盖 Leaflet、jsPDF、html2canvas、marked、mammoth、DOMPurify。

HIGH 自建 HTML 净化器不足以防御高级 XSS 向量 SEC-004

问题：原有正则净化器无法处理变异 XSS（如 SVG 嵌套、data URI 脚本、Unicode 编码绕过）。

修复方案：

引入 DOMPurify 3.1.6（Cure53 维护的行业标准库）作为主净化器，保留正则方案作为 CDN 加载失败时的降级回退。配置 ALLOWED_TAGS 白名单仅保留 strong/ul/li 等安全标签。

HIGH Service Worker 缓存所有 GET 请求导致数据过期 SEC-005

问题：SW 缓存策略过于宽泛，导致天气 API 等动态数据返回过期内容。

修复方案：

将 SW 提取为独立 sw.js 文件，缓存策略限制为仅缓存高德地图瓦片（autonavi.com），其他请求直接放行至网络。

MEDIUM 导入文件缺少大小限制和结构验证 SEC-006

问题：文件导入无大小限制，恶意大文件可导致内存耗尽；JSON 导入无 Schema 验证。

修复方案：

添加文件大小限制（攻略 10MB / 数据 10MB），实现 validateSchema() 方法覆盖所有数据结构字段验证，导入预览界面显示彩色徽章验证结果，结构性错误时弹出二次确认。

MEDIUM 内联 onclick 事件处理器违反 CSP 最佳实践 SEC-007

问题：残留的内联 onclick 属性与 CSP 安全策略冲突。

修复方案：

将所有内联 onclick 重构为 addEventListener 事件绑定模式。

LOW 分类配置值未转义 SEC-008

问题：8 个预算分类配置值（emoji、名称）直接插入 innerHTML，虽为内部数据但不符合纵深防御原则。

修复方案：

对所有分类配置值统一应用 escapeHtml() 转义。

无障碍审计

10项 · 全部修复
HIGH 缺少 ARIA 语义标签和导航角色 A11Y-001

问题：页面结构缺少 ARIA 角色（banner、main、tablist、tab），屏幕阅读器无法正确识别页面结构。

修复方案：

为 header 添加 role="banner"，主内容区添加 role="main"，标签栏改为 <nav role="tablist">，各标签按钮添加 role="tab" 和 aria-selected，图标 SVG 添加 aria-hidden="true"，所有按钮添加 aria-label。

HIGH 动态内容区域缺少 aria-live 通告 A11Y-002

问题：倒计时、天气、搜索结果、截止提醒等动态更新区域无 aria-live，屏幕阅读器用户无法感知内容变化。

修复方案：

为倒计时添加 aria-live="polite" aria-atomic="true"，截止提醒添加 role="alert"，天气和搜索结果添加 aria-live="polite"，日期徽章添加 aria-live="polite"。

MEDIUM 未支持 prefers-reduced-motion 用户偏好 A11Y-003

问题：大量 CSS 动画未考虑前庭功能障碍用户的需求。

修复方案：

添加 @media(prefers-reduced-motion:reduce) 媒体查询，将所有动画时长降至 0.01ms，禁用平滑滚动。

MEDIUM 缺少键盘导航焦点指示器 A11Y-004

问题：键盘 Tab 导航时无可见焦点环。

修复方案：

添加 :focus-visible 样式，显示 2px 紫色轮廓，标签按钮使用内偏移焦点环。

LOW 缺少跳转到主内容的快捷链接 A11Y-005

问题：键盘用户需多次 Tab 才能到达主内容区。

修复方案：

添加 .skip-link 跳转链接，默认隐藏，获得焦点时显示。

LOW 深色模式未设置 color-scheme 属性 A11Y-006

问题：深色模式下原生控件（滚动条、输入框、下拉选择）仍显示浅色样式。

修复方案：

添加 :root[data-theme="dark"]{color-scheme:dark} 和 :root{color-scheme:light}。

性能与交互优化

10项 · 全部修复
MEDIUM CDN 资源未配置 preconnect 预连接 PERF-001

问题：三个 CDN 源（unpkg、cdnjs、jsdelivr）未预连接，首次加载存在 DNS+TLS 握手延迟。

修复方案：

添加 <link rel="preconnect"> 标签预连接所有 CDN 源。

MEDIUM 动态图片未使用 loading=lazy 懒加载 PERF-002

问题：日记照片、票务截图、相册图片在页面加载时全部请求，影响首屏性能。

修复方案：

为所有动态生成的 <img> 标签添加 loading="lazy" 属性。

MEDIUM transition: all 导致不必要的性能开销 PERF-003

问题：多处使用 transition: all，触发非必要属性动画，增加合成层开销。

修复方案：

替换为具体属性列表（background-color, border-color, color, box-shadow），已确认全文无残留 transition: all。

LOW 缺少触摸交互优化 UX-001

问题：移动端按钮存在 300ms 双击缩放延迟，模态框滚动可穿透到背景。

修复方案：

为所有交互元素添加 touch-action: manipulation，模态框和照片查看器添加 overscroll-behavior: contain。

LOW 数据展示缺少 tabular-nums 等宽数字 UX-002

问题：预算金额、统计数据使用比例数字，列对齐不整齐。

修复方案：

为统计卡片、费用金额、预算总额等添加 font-variant-numeric: tabular-nums。
